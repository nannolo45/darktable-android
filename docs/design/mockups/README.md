# Mockup sources

Interactive mockups the interface specification (`../ui-spec.md`) is based on. Each file is one screen: HTML with inline styles inside an `<x-dc>` element, and a small JavaScript class in a `<script type="text/x-dc">` block that holds its behaviour. They were written for a design canvas tool and do not run on their own (`support.js` is not included). Read them for exact sizes, colours, texts and interaction logic. The photo in them is a drawn placeholder and the image effects are rough approximations.

| File | Screen |
|---|---|
| `B2-Phone.html` | darkroom, phone |
| `B2-Tablet.html` | darkroom, tablet |
| `B3-Masks.html` | masks and blending |
| `B3-Crop.html` | crop on the photo |
| `B3-ToneEq.html` | tone equalizer graph |
| `B3-Snapshots.html` | snapshots with split view |
| `B3-Export.html` | export |
