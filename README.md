# darktable-android

An unofficial Android port of [darktable](https://www.darktable.org): darktable's own processing engine, unmodified, under a touch interface for phone and tablet. Edits are stored as normal darktable XMP sidecars, so they open in desktop darktable and the other way round. Photos come from and go back to LightPhotoLibrary, a separate library app.

Status: Phase 0 (feasibility experiments). Nothing here is usable yet.
