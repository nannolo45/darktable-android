# X-Trans image, top-left corner region (all differences within 10 px of the image's
# own top and left edge). lens (embedded metadata) _modify_roi_in_md() (iop/lens.cc)
# asks demosaic for the input bounding box of the window's own border: for a corner
# window that box starts at raw (131,78), for the whole image at (103,2), so
# Markesteijn demosaic (iop/demosaicing/xtrans.c) interpolates the raw pixels next to
# the image edge as border pixels of its window in the region and as inner pixels in
# the full render. A margin cannot move a window that already starts at the image edge;
# only a window reaching the middle of the image's left and top edges would (5x more
# pixels). Not a bridge error.
raf base 1 11 0.0077
